# Programa De Superficies

Objetivo: mantener la vivienda principal inferior entre 100 y 120 m2 interiores/construidos ajustados, sin perder comodidad, y controlar por separado el bloque alto de garaje/servicios.

## Vivienda Principal

| Estancia | Superficie objetivo |
|---|---:|
| Salon-comedor-cocina | 36-44 m2 |
| Dormitorio principal | 13-15 m2 |
| Bano principal | 5-7 m2 |
| Dormitorio invitados | 10-11 m2 |
| Despacho / estudio sonido | 9-11 m2 |
| Segundo bano | 4-5 m2 |
| Lavadero compacto / apoyo domestico | 3-5 m2 |
| Vestibulo, circulacion y armarios | 12-16 m2 |
| **Total vivienda inferior objetivo** | **92-114 m2** |

## Bloque Alto En Cota Calle

| Elemento | Superficie objetivo |
|---|---:|
| Garaje doble | 32-38 m2 |
| Trastero | 5-8 m2 |
| Sala de maquinas / energia / comunicaciones | 6-10 m2 |
| Gimnasio con vistas | 10-16 m2 |
| **Total bloque alto objetivo** | **53-72 m2** |

## Exterior Cubierto Y Plataforma Inferior

| Elemento | Superficie objetivo |
|---|---:|
| Porche principal | 30-45 m2 |
| Porches secundarios | 5-15 m2 |
| Patio pavimentado | 40-80 m2 |
| Piscina ornamental opcional | 6-12 m2 |
| Cubierta fotovoltaica sobre bloque alto | Segun superficie util disponible |

## Control De Riesgo

Con presupuesto maximo de 300.000 EUR, la vivienda debe evitar:

- pasillos largos;
- estancias sobredimensionadas;
- demasiadas esquinas;
- grandes voladizos estructurales;
- carpinterias excesivas sin proteccion solar;
- acabados premium en toda la vivienda;
- piscina convencional desde fase 1;
- sobredimensionar el bloque alto hasta convertirlo en una segunda vivienda encubierta;
- sala tecnica sin acceso, ventilacion, drenaje y aislamiento acustico adecuados;
- cubierta solar con sombras propias, petos excesivos o mala orientacion.
