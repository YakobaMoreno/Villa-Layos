# Alternativas De Implantacion

Comparativa inicial de tres familias volumetricas.

## Alternativa 1 - U Ligera

La vivienda y el garaje/anexo forman tres lados alrededor de un patio protegido. No toda la U es vivienda climatizada.

```text
Dormitorios / estudio       Salon - comedor - cocina
----------------------      ------------------------
| Principal          |      | Gran ventanal        |
| Invitados          | Patio| Cocina abierta       |
| Estudio            |porche| Salon                |
----------------------      ------------------------
              Garaje doble / trastero / gym
```

### Ventajas

- Mejor equilibrio entre imagen de U y control de coste.
- Patio central protegido y privado.
- Garaje integrado en la composicion.
- Compatible con vivienda de 100-120 m2.
- Buena base para porches amplios.

### Riesgos

- Puede perder superficie en circulaciones si no se dibuja con precision.
- El patio debe orientarse bien para no quedar excesivamente caliente o sombrio.

## Alternativa 2 - L Con Pergola

La casa es una L racional y una pergola o porche completa la percepcion espacial de U.

```text
Salon - cocina - comedor
------------------------
| Gran ventanal        |
| Porche / pergola     |
--------------------------------
Dormitorios / estudio    Garaje |
---------------------    -------
```

### Ventajas

- Probablemente la opcion mas economica.
- Menor envolvente, cubierta y cimentacion.
- Muy compatible con sistemas panelizados.
- Facil de ampliar o ajustar.

### Riesgos

- Menor fuerza espacial que una U real.
- Menor sensacion de patio abrazado.

## Alternativa 3 - U Compacta

La vivienda abraza claramente un patio central. Es la opcion mas arquitectonica y tambien la mas exigente economicamente.

```text
Dormitorios           Salon - comedor - cocina
-----------           ------------------------
| Principal|         | Gran ventanal        |
|Invitados |  Patio  | Cocina               |
|Estudio   | central | Salon                |
-----------           ------------------------
           Acceso / garaje / zona tecnica
```

### Ventajas

- Mayor impacto arquitectonico.
- Patio central muy privado.
- Muy buena relacion visual entre salon, dormitorio y porches.
- Admite muy bien una lamina de agua pequena.

### Riesgos

- Mayor coste por perimetro, cubierta, cimentacion y esquinas.
- Mas dificil de encajar en 300.000 EUR sin renuncias.
- Requiere disciplina fuerte en metros y detalles.

## Recomendacion Actual

La opcion base recomendada es la **U ligera**. Permite obtener la experiencia espacial deseada sin que toda la forma en U sea superficie interior costosa.

La **L con pergola** debe mantenerse como alternativa de control economico.

La **U compacta** debe tratarse como opcion aspiracional, viable solo si la parcela, el sistema constructivo y el presupuesto real lo permiten.
